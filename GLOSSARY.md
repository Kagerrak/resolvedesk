# ResolveDesk glossary

This glossary records agreed domain language. It contains no implementation choices.

| Term | Meaning |
|---|---|
| Workspace | An isolated support operation belonging to one business. |
| Member | A person authorized to access a workspace. |
| Admin | A member who manages workspace membership, knowledge, and connections. |
| Agent | A member who handles tickets, reviews drafts, and approves permitted support actions. |
| Viewer | A member who can inspect permitted workspace information without changing it. |
| Customer | The person seeking assistance; distinct from a workspace member. |
| Ticket | A support case containing a conversation and its handling history. |
| Message | One customer or agent contribution to a ticket conversation. |
| Knowledge document | An approved source of support information. |
| Document version | A specific revision of a knowledge document. |
| Citation | A reference identifying the source passage supporting a statement. |
| Draft reply | A proposed customer response that has not been sent. |
| Proposed action | A suggested change to a ticket or connected system that has not been executed. |
| Approval | A member's explicit authorization of a specific reply or action. |
| Escalation | A request for human judgment when the available knowledge or authority is insufficient. |
| Connector | A connection between a workspace and an external communication or business service. |
| Audit event | A record of a meaningful action and who or what performed it. |
