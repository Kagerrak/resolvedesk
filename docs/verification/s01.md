Verified 14 November 2026. Fixture mode only; no OpenAI requests or Gmail activity.

## Automated evidence

- Real HTTP + Better Auth + PostgreSQL scenarios: **23 assertions passed**. Anonymous identity, distinct visitor workspaces, message persistence, stable reload, fixed session lifetime, cross-workspace denials, forged identity rejection, origin validation, concurrent bootstrap deduplication, role revocation, Viewer reads, unavailable mutation routes, composite ownership constraint, session/workspace expiry and sign-out.

- Clean GitHub CI runs the same application against a disposable PostgreSQL container. Run: https://github.com/Kagerrak/resolvedesk/actions/runs/43590409457 (final status recorded on PR).

## Interactive ego-browser evidence

- Entry creates a private persisted workspace; ticket and theme survive reload.
- Desktop light/dark screenshots inspected; mobile 390px light/dark screenshots inspected.
- No horizontal overflow at 360, 390, 768, 1280 and 1440px with reduced motion enabled.
- Keyboard Enter opens the selected ticket, focuses its heading, and Back returns focus to the queue row.
- A temporary second authorized workspace loads its own ticket and Viewer explanation; the previous conversation disappears. Temporary QA workspace removed afterward.
- Viewer has no mutation controls. Expired session clears content and links to demo entry; fresh entry successfully opens another workspace.
- Expired workspace with a still-valid session shows an empty authorized list without stale conversation content; entry recovery signs out the expired workspace identity and opens a fresh persisted ticket successfully.
- Twelve tested semantic color pairs pass their WCAG text/control thresholds; actual computed values in s01-contrast.json. This is not a full accessibility certification.
- 200% CSS zoom reflow passes without horizontal overflow. Native browser zoom shortcuts did not change the viewport; native 200% zoom remains unverified and is retained for S13 final accessibility QA.
